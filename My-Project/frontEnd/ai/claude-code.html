Claude Code ​

安装 ​

bash
npm uninstall -g @anthropic-ai/claude-code
1

启动 ​

  • 必读
    • settings.json：权限 钩子配置
    • CLAUDE.md：你是谁 项目说明
    • rules/*.md：行为规范 硬性准则
    • MEMORY.md：记忆索引（自维护）
  • 按需加载
    • Agents 子代理（独立上下文）
    • Skills 技能模版（工作流）
    • Commands 斜杠命令
    • MCP 外部工具服务

接入阿里云百炼 ​

阿里云百炼模型用量website

bash
setx ANTHROPIC_API_KEY "API_KEY"
setx ANTHROPIC_BASE_URL "https://dashscope.aliyuncs.com/apps/anthropic"
setx ANTHROPIC_MODEL "deepseek-v4-pro"

echo %ANTHROPIC_API_KEY%
echo %ANTHROPIC_BASE_URL%
echo %ANTHROPIC_MODEL%

安装 & 使用 ​

项目级：/.claude/skills

  • zip安装，下载skill压缩包，解压到 /.claude/skills 目录下
  • 命令行安装，在skill下载平台上复制命令执行

安装完成可以通过/skills查看已安装的技能
